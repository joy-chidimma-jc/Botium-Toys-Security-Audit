# Botium-Toys-Security-Audit

## Project Overview

This project involved conducting an **internal security audit and risk assessment** of **Botium Toys**, a fictional company used for cybersecurity training.

The objective was to assess the organization's existing security controls and compliance practices, identify security gaps and risks, and provide recommendations to improve its overall security posture.

> **Disclaimer: This project was completed as part of a cybersecurity training course using the fictional company Botium Toys. It is an educational exercise and does not represent an audit of a real organization.**

## Audit Scope

The audit covered the organization's overall security program, including:

* Employee devices and equipment
* Internal network and systems
* Business applications and databases
* Data storage and retention
* Legacy systems
* Physical security
* Security controls
* Compliance practices

## Risk Assessment

The assessment identified **inadequate asset management** and several missing or insufficient security controls.

**Overall Risk Score: 8/10 — High Risk**

The assessment identified significant risks involving access to sensitive information, data protection, business continuity, and compliance.

## Key Findings

The audit identified the following major security gaps:

* **Least privilege:** Not implemented
* **Separation of duties:** Not implemented
* **Encryption:** Not implemented for customer credit-card information
* **Intrusion Detection System (IDS):** Not implemented
* **Backups:** Critical data was not backed up
* **Disaster recovery:** No disaster recovery plan existed
* **Password security:** Existing password requirements were insufficient
* **Password management:** No centralized password management system
* **Asset management:** Inadequate asset management practices
* **Legacy systems:** Monitoring and maintenance procedures lacked a regular schedule

Existing controls included a **firewall, antivirus software, physical locks, CCTV surveillance, and fire detection/prevention systems**.

## Compliance Assessment

The project also assessed selected best practices related to:

* **PCI DSS** — payment card data security
* **GDPR** — protection of customer data and breach notification
* **SOC controls** — access, confidentiality, integrity, and availability

The assessment identified gaps primarily involving access control, protection of sensitive information, encryption, and password management.

## Recommendations

Based on the identified risks, the key recommendations were:

1. Implement **least-privilege access controls** and separation of duties.
2. Encrypt sensitive and cardholder data.
3. Establish regular backups and develop a disaster recovery plan.
4. Strengthen password requirements and implement centralized password management.
5. Deploy an intrusion detection system.
6. Develop a comprehensive asset inventory and classification process.
7. Establish formal monitoring and maintenance procedures for legacy systems.
